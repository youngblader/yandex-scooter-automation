# Yandex Scooters Test Automation

## Getting Started

Follow these instructions to run the automated tests on your machine.

Clone the repo:

```bash
git clone https://github.com/youngblader/yandex-scooter-automation.git
```

Open the project in your IDE and run the tests using Maven:

```bash
mvn test
```

## Built with

- Java
- Selenium WebDriver
- JUnit 5
- Maven
